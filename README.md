Lumen 0.1.0

Lumen is a free software for photo editing

How to install Lumen:
1. Extract the zip
2. Go to the lumen > lumen folder. For example, if downloaded into your downloads folder, the file path should be Downloads > lumen > lumen
3. Right click anywhere in the folder and select "Open in Terminal"
4. Once in Terminal, run the command "npm install"
5. After the installation is complete, run the command "npm start"
